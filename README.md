# RIVEN

A weighty, tactical **1v1 fantasy duel fighter** in the spirit of *Shadow Fight 2* —
dark silhouette warriors with glowing, per-fighter accent colors, a medieval-martial
arsenal, and spacing-and-timing combat where one clean hit hurts.

- **Engine:** Godot 4.7.2 (Compatibility / OpenGL renderer)
- **Targets:** Windows/PC for development, Web (HTML5) for play in iPhone Safari; native iOS possible later
- **Status:** Phase 0 — project foundation

See [DESIGN.md](DESIGN.md) for the full vision and the development roadmap.

## Running the project

1. Open `C:\GODOT\Godot_v4.7.2-stable_win64.exe`.
2. Import this folder (select `project.godot`).
3. Press **F5** to run.

### Default controls (PC)

| Action | Keys |
|---|---|
| Move left / right | A / D (or ← / →) |
| Jump | W / ↑ / Space |
| Crouch | S / ↓ |
| Attack | J |
| Kick | K |
| Block | L |
| Magic | I |
